## 2. Captains and sub-captains

Captain/sub-captain is defined by `variantClassification` in `lbl_801094E4` (`src/main/file_80069BDC.c:1375`): 0=PRIMARY_CAPTAIN, 1=SECONDARY_CAPTAIN.

| Team (CHALLENGE_CAPTAIN) | Captain | Sub-captain |
|---|---|---|
| 0 MARIO | Mario | Luigi |
| 1 PEACH | Peach | Daisy |
| 2 WARIO | Wario | Waluigi |
| 3 DK | Donkey Kong | Diddy Kong |
| 4 YOSHI | Yoshi | Birdo |
| 5 BOWSER | Bowser | Bowser Jr. |

`lbl_800E854C[12] = {0,1,4,5,10,11,6,17,2,3,9,19}` (`src/main/data_800E8300.c:87`) is not itself a captain/sub-captain table in code: it is only used as the pool of 12 captain-capable characters for random CPU picks in minigames (`src/game/auto_00_00106DFC_text.c:2270-2273` copies it into `pool[]` and shuffles; `:3536-3554` picks a random unused entry for CPU slots). It happens to list the 6 pairs (primary then secondary) in the order Mario, Peach, Wario, Yoshi, DK, Bowser. The same 12 characters have `StatTable.Captain=1` (stat offset 0x33) and `CharTableEntry._4=1` (all others 0).
Related tables: `lbl_803CB8F0[8] = {0,4,10,2,6,9,0,0}` (`src/main/file_80069BDC.c:2284`) maps CHALLENGE_CAPTAIN -> captain char id; `lbl_80108EC4[12] = {0,4,10,2,6,9,1,5,11,3,17,19}` (`src/main/file_800639BC.c:1637`) maps preset-team index -> captain char id (6 primaries, then Luigi, Daisy, Waluigi, Diddy, Birdo, Bowser Jr.).

## 3. Challenge Mode default teams

Two independent sources agree (asserted in the script):

* Per-character `challengeCaptain` (byte 0) and `variantClassification` (byte 1) come from `lbl_801094E4` (`src/main/file_80069BDC.c:1375`, 0x1C bytes per character; the record is the `ScoutFlagTable` that `ChallengeTrackingStruct.scoutFlagPointer` points to). They are copied into the tracker by `fn_2_46ADC` (`src/menus/auto_00_0003C03C_text.c:1867-1888`, new game) and `fn_2_468DC` (`:1997-2005`). Bytes 2-3 are unknown; bytes 4..27 are a [4][6] scout/limit table indexed `[_4415*6 + _441C + 4]` (`include/menus/menu_work.h:146`).
* New game: `chars[i]._31` (CHALLENGE_RECRUITMENT_CD) = RECRUITED(1) iff `challengeCaptain == chosen captain && variantClassification <= 3` (`src/menus/auto_00_0003C03C_text.c:1882-1886`). So the secondary color variants are not flagged themselves; they become usable through their primary variant (`fn_80067AC8` alt lookup, `src/menus/auto_00_00001254_text.c:3801-3812`).
* The full 9-man team lineup is preset row 0 of `presets[captainIdx]` in the stats file on disc (ZZZZ.dat+0x06CF8800, +0x4380, 0x48 bytes per preset; `include/main/charsel_state_type.h:17`). It is copied into the team slots/ `gChallengeState.teams[]` when starting a challenge (`src/main/file_800639BC.c:1388-1408`, `src/menus/rep_0438.c:121-125`), and used for the CPU opponent team (`src/menus/auto_00_00001254_text.c:1514-1520`). Preset row 1 lists exactly the characters with the recruited flag at start.

## 4. Character stats

Source: the 0x46E0-byte character file on disc, `ZZZZ.dat` offset 0x06CF8800 (uncompressed DiskFileEntry `{0, 0x46E0, 0x06CF8800, 0x46E0}` at `src/menus/rep_0010.c:59` and `src/game/rep_0.c:11`). It is loaded to `lbl_8034E9A0` (CharSelectState, `roster[6][9]` indexed `[id/9][id%9]`, `include/main/charsel_state_type.h:15`) and per-team copies are made into `inMemRoster` (`src/game/rep_0.c:147-148`). Record = `CharacterStats` 0xA0 bytes (`include/game/character_stats.h:102-115`); first 0x3B bytes = `StatTable` (`:9-39`), then chemistry[54] at 0x3B. Bytes 0x05-0x1F are zero for all 54. The character-select screen draws the 4 bars from `BattingStatBar`/`PitchingStatBar`/`RunningStatBar`/`FieldingStatBar` (`src/menus/auto_00_00071EC4_text.c:4133-4137`).

Field offsets: 0x00 CurveBallSpeed, 0x01 FastBallSpeed, 0x02 cursedBall, 0x03 Curve, 0x04 curveControl, 0x20 FieldingStats (u32 FIELDING_ABILITIES bits, `include/game/UnknownHomes_Game.h:1483-1500`), 0x24 CharID, 0x26 FieldingArm, 0x27 BattingStance (BATTING_HAND 0=right,1=left, `mssbTypes.h:139-142`), 0x28 SlapContactSize, 0x29 ChargeContactSize, 0x2A SlapHitPower, 0x2B ChargeHitPower, 0x2C BuntingContactSize, 0x2D HitTrajectoryPushPull, 0x2E HitTrajectoryHighLow, 0x2F Speed, 0x30 ThrowingArm, 0x31 CharacterClass, 0x32 Weight, 0x33 Captain, 0x34 CaptainStarHitPitch, 0x35 NonCaptainStarSwing, 0x36 NonCaptainStarPitch, 0x37 BattingStatBar, 0x38 PitchingStatBar, 0x39 RunningStatBar (=Speed bar), 0x3A FieldingStatBar.
